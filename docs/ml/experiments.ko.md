# 실험 기록

블럭 분할 모델 실험의 수치 결과입니다. 설계와 판단은 [설계](design.md)에 있고, 여기에는 각 실험의 설정과 숫자를 모읍니다. 새 실험을 하면 표를 추가합니다.

## 공통 설정

- **데이터**: `labels/labels.jsonl` 300건(사람 검토 `human` 149건, LLM 초안 `auto` 151건). 학습에는 둘 다, 채점에는 `human`만 씁니다.
- **채점 규모**: 149건, 3,114문장. 블럭 묶기는 정답 종류를 준 상태에서 logic 문장만 묶은 점수입니다.
- **교차 검증**: 풀이 단위 5-fold(`KFold(5, shuffle=True, random_state=0)`). 각 fold의 학습 풀이는 fit 80% / dev 20%로 다시 나눕니다.
- **지표**: 종류는 문장 단위 macro-F1. 블럭 묶기는 B³, CEAF-e, 같은 블럭 쌍 정밀도(P) / 재현율(R) / F1. 쌍 P가 낮으면 잘못 합친 것, R이 낮으면 잘못 나눈 것입니다.
- **전체(end to end)**: 예측한 종류로 logic 문장을 고른 뒤 묶은 결과를, input / output / none을 각각 한 묶음으로 보고 매긴 점수입니다. 비 logic 문장이 큰 묶음으로 잡혀 블럭 묶기 점수보다 높게 나옵니다.
- **잡음**: 채점 149건에서 B³ 약 0.026, 종류 F1 약 0.023 미만의 차이는 실제 차이로 확정할 수 없습니다([평가 잡음](#평가-잡음)).

## 평가 잡음

설정: 7의 100% 실행에서 채점 풀이 149건을 1,000번 부트스트랩. "실제 차이로 볼 수 있는 크기"는 독립된 두 실행의 차이가 표준오차의 약 2.83배를 넘는 기준이고, 채점 풀이 수의 제곱근에 반비례한다고 보고 늘렸을 때를 계산했습니다. 같은 평가셋에서 두 설정을 비교하면 실제 기준은 이보다 조금 작습니다.
